# App Store 描述（中文）

## TidyZen — AI 整洁度分析与个性化整理建议

TidyZen 是一款由 AI 驱动的房间整理助手。只需拍一张房间照片，TidyZen 就能识别桌面、卧室、客厅、厨房、卫生间等典型场景的杂乱物品，给出 0–100 分的整洁度评分，并附上"该收纳什么、该如何摆放、改善的优先顺序"等可执行的整理建议。

—— 核心功能 ——
• 一键拍照 / 相册选图，AI 自动识别物品种类与位置（含置信度），框选关键杂物。
• 整洁得分 + 趋势分析：每次整理后查看分数变化与历史曲线，让"变整洁"被看见。
• 个性化整理建议：基于场景的 20+ 条建议库（含黄金比例法、分区收纳、垂直空间利用等），并预留图文教程入口。
• Before / After 对比：保留每一次整理记录，前后对比一目了然。
• 氛围与心理小贴士：弱光环境提醒、整理减压名言，让收纳变成一件愉悦的事。
• 全离线优先：照片不强制上传，识别结果存储在本地，照顾你的隐私。

适合学生宿舍、独居青年、宝妈家庭、共享办公空间——任何想让生活空间"清爽一点点"的人。
打开 TidyZen，拍一张照片，让 AI 陪你 5 分钟变整洁。
