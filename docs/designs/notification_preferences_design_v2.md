# 通知偏好设置页面设计稿描述（更新版）

## 页面整体布局
- 垂直单栏模块化布局
- 浅灰色背景（#F5F5F5）
- 白色圆角卡片做视觉分层
- 从上到下：顶部导航栏、通知内容设置区、发送时间设置区、通知方式设置区、引导提示框、底部导航栏

## 顶部导航栏
- 背景：与页面背景一致的浅灰色
- 左侧：深绿色线条式向左箭头（返回按钮），宽度适中
- 中间偏左：页面标题"通知偏好"，深灰色（#333333），字号18-20pt，粗体
- 间距：导航栏高度约56-60px，返回箭头与左侧页面边距16px，标题与箭头水平间距12px

## 通知内容模块
- 模块标题：深灰色（#666666）文字"通知内容"，左对齐，字号14-16pt，与下方白色卡片垂直间距12px
- 承载卡片：白色（#FFFFFF）背景，圆角12-16px
- 卡片内4个通知选项，选项间用1px浅灰色（#E0E0E0）分隔线隔开

### 选项细节
- 左侧：通知名称，深灰色（#333333）文字，字号16pt
- 右侧：双状态开关
  - 开启状态：开关背景浅绿色（#C8F4E3），滑块深绿色（#1A7354），滑块居右
  - 关闭状态：开关背景浅灰色（#E0E0E0），滑块白色（#FFFFFF），滑块居左
- 选项行高度：48-52px
- 开关与右侧页面边距16px，文字与开关水平间距16px

### 选项列表
1. 整理提醒通知 - 开启
2. AI 分析完成通知 - 开启
3. 每日整洁度报告 - 关闭
4. 建议更新通知 - 开启

## 发送时间模块
- 模块标题：深灰色文字"发送时间"，与下方卡片垂直间距12px
- 承载卡片：白色圆角卡片，2个时间设置选项，选项间1px浅灰色分隔线

### 选项细节
- 左侧：设置项名称，深灰色文字
- 右侧：当前时间（深绿色）+ 深绿色线条式向右箭头
- 选项行高度与"通知内容"模块一致

### 选项列表
1. 整理提醒时间 - 19:00
2. 报告推送时间 - 08:30

## 通知方式模块
- 样式与前两个模块高度统一
- 3个选项，均为开启状态的双色开关

### 选项列表
1. 推送通知 - 开启
2. 声音提醒 - 开启
3. 震动提醒 - 关闭

## 引导提示框
- 背景：浅绿色（#E6F7EE），圆角12-16px，与上方卡片垂直间距16px
- 左侧：深绿色线性灯泡图标
- 右侧：引导文字，深绿色（#1A7354）字体，字号14-15pt，行间距1.6倍
- 文案："合理的通知设置能帮助您养成每天整理的小习惯。通过AI分析和实时提醒，我们将共同打造一个更舒适的生活空间。"
- 内边距上下左右均为16px

## 底部导航栏
- 背景：白色（#FFFFFF），高度56-60px
- 4个入口：首页、整理、通知、我的
- 普通状态：深灰色线条图标 + 深灰色文字（#333333），字号12-13pt
- 选中状态（通知）：深绿色图标和文字（#1A7354）+ 浅绿色圆形遮罩背景
- 4个入口均匀分布，左右边距16px

## 精确复刻关键点
1. **开关样式**：浅绿色背景（#C8F4E3）+ 深绿色滑块（#1A7354），不是纯深绿色
2. **引导提示框**：浅绿色背景（#E6F7EE），灯泡图标，新文案
3. **底部导航**：4个入口（首页、整理、通知、我的），不是3个
4. **模块标题**：深灰色（#666666），与卡片间距12px
5. **分隔线**：1px浅灰色（#E0E0E0），不贴边
6. **圆角**：12-16px，更圆润
