# 图文整理秘籍弹窗 设计稿描述

## 弹窗整体结构
全屏卡片式模态弹窗，白色背景（#FFFFFF），圆角矩形。

### 顶部标题栏
- 左侧：绿色灯泡图标（💡）+ 标题文字「整理秘籍：办公桌线缆」
- 标题颜色：#333333，18px，加粗
- 右侧：灰色「X」关闭按钮，颜色 #999999
- 标题栏高度约 56px

### 内容区域（可垂直滚动）
采用单列瀑布流布局：图片在上，步骤文字在下。

#### 视觉展示区
- 全宽图片，展示长尾夹固定线缆的实际效果
- 图片左下角有深绿色圆角标签：「✨ 长尾夹的大妙用」
  - 标签背景：#2D7A5A（深绿），文字：#FFFFFF
  - 标签字号：12px

#### 步骤说明区
3 个步骤，左对齐布局：
- 步骤序号：圆形徽章，直径 32px
  - 背景：#D4F5E3（浅绿）
  - 数字：#3E9E77（中绿）
- 步骤间通过垂直细灰线（#E0E0E0）连接，形成步骤引导
- 步骤标题：16px，加粗，#000000
- 步骤描述：14px，常规，#555555
- 步骤标题与描述间距：8px
- 步骤与步骤间距：24px

### 底部操作栏
- 主按钮：「我已完成整理」
  - 背景：#1F6B4D（深绿），胶囊形大圆角
  - 文字+图标：#FFFFFF（白色），左侧有白色对勾圆圈图标
  - 字号：16px，中等字重
  - 内边距：水平 16px，垂直 14px
  - 按钮占据底部大部分宽度，两侧有内边距

## 间距
- 弹窗整体内边距：左右 24px，顶部 16px
- 标题栏与内容间距：16px
- 图片与下方文字间距：20px
- 底部按钮与内容间距：16px

## 背景遮罩
- 覆盖整个屏幕的半透明黑色遮罩
- rgba(0, 0, 0, 0.5)
- 点击遮罩可关闭弹窗
- z-index 低于弹窗但高于页面内容
