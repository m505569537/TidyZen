# 通知偏好设置页面设计稿描述

## 页面整体布局
- 垂直滚动页面，从上到下：顶部导航栏、分组设置区域、「小贴士」卡片、底部全局导航栏
- 页面背景：浅灰白色（#F5F7FA）

## 顶部导航栏
- 布局：左对齐导航，高度固定 56dp
- 左侧：深绿色（#1A3C34）返回箭头图标（24dp），与页面左边缘间距 16dp
- 标题：「通知偏好」，深绿色（#1A3C34）加粗字体，字号 18sp，与返回箭头间距 12dp
- 背景：与页面背景一致

## 分组设置区域（共3组）

### 通用设计
- 分组标题：灰色（#666666）常规字体，字号 14sp，左对齐，与下方卡片间距 12dp
- 设置卡片：白色（#FFFFFF）圆角卡片，圆角 12dp
- 选项分隔线：浅灰色（#EEEEEE），1dp

### 1. 「通知内容」分组
卡片内共4个「左文字+右开关」选项：
- 选项内上下间距 16dp
- 文字与卡片左边缘、开关与卡片右边缘间距均为 16dp

| 选项文字 | 开关状态 |
|---------|---------|
| 整理提醒通知 | 开启：深绿色（#1A3C34）轨道+白色圆形滑块；高度24dp，宽度48dp |
| AI 分析完成通知 | 开启 |
| 每日整洁度报告 | 关闭：浅灰色（#E0E0E0）轨道+浅灰色（#BDBDBD）圆形滑块 |
| 建议更新通知 | 开启 |

- 选项文字：深黑色（#222222），字号 16sp

### 2. 「发送时间」分组
卡片内共2个「左文字+右时间+箭头」选项：
- 选项内上下间距 16dp
- 文字与卡片左边缘间距 16dp

| 选项文字 | 时间信息 | 箭头 |
|---------|---------|-----|
| 整理提醒时间 | 深绿色（#1A3C34）字体 19:00 | 深绿色向右箭头（16dp），与时间间距 8dp |
| 报告推送时间 | 深绿色字体 08:30 | 深绿色向右箭头 |

- 选项文字：深黑色（#222222），字号 16sp

### 3. 「通知方式」分组
卡片内共3个「左图标+文字+右开关」选项：
- 选项内上下间距 16dp
- 图标与文字间距 8dp
- 文字与卡片左边缘、开关与卡片右边缘间距均为 16dp

| 选项图标 | 选项文字 | 开关状态 |
|---------|---------|---------|
| 深绿色铃铛图标（20dp） | 推送通知 | 开启 |
| 深绿色喇叭图标（20dp） | 声音提醒 | 开启 |
| 深绿色震动图标（20dp） | 震动提醒 | 关闭 |

- 选项文字：深黑色（#222222），字号 16sp

## 「小贴士」卡片
- 背景：浅薄荷绿（#E6F7F0），圆角 12dp，与上方「通知方式」卡片间距 16dp
- 内部布局：
  - 左侧：白色（#FFFFFF）圆角小方块（8dp圆角，48dp尺寸），内部是深绿色叶子图标（24dp）
  - 右侧：
    - 标题「小贴士」：深绿色（#1A3C34）加粗字体，字号 16sp
    - 正文：深灰色（#444444）常规字体，字号 14sp，行间距 1.5
    - 内容：「合理的通知设置能帮助您养成每天整理的小习惯。准时的提醒就像一位温和的伙伴，在您最需要的时候给予指引，让整洁成为您生活的一部分。」
- 内边距：卡片上下左右均为 16dp，左侧图标与右侧文字区域间距 12dp

## 底部全局导航栏
- 布局：固定底部导航，高度 64dp，等分4个导航项
- 顶部有浅灰色（#EEEEEE，1dp）分隔线

| 导航名称 | 图标+文字样式 | 状态 |
|---------|-------------|-----|
| 首页 | 深灰色（#999999）房子图标+「首页」灰色文字（12sp） | 非选中 |
| 计划 | 深灰色日历图标+「计划」灰色文字（12sp） | 非选中 |
| 通知 | 深绿色铃铛图标+「通知」深绿色文字（12sp） | 选中：外层包裹浅薄荷绿（#E6F7F0）圆角背景（12dp圆角） |
| 我的 | 深灰色人形图标+「我的」灰色文字（12sp） | 非选中 |

- 间距：每个导航项的图标与文字间距 4dp，导航项在栏内上下居中

## 精确复刻关键点
1. **颜色体系**：
   - 主色：深绿色 #1A3C34
   - 背景：浅灰白 #F5F7FA
   - 卡片：白色 #FFFFFF
   - 分隔线：浅灰 #EEEEEE
   - 小贴士背景：浅薄荷绿 #E6F7F0
   - 文字：深黑 #222222、灰色 #666666、深灰 #444444

2. **圆角**：
   - 卡片：12dp
   - 开关：全圆角
   - 图标容器：8dp

3. **间距**：
   - 选项内间距：16dp
   - 卡片内边距：16dp
   - 分组标题与卡片间距：12dp

4. **字体**：
   - 标题：18sp 加粗
   - 选项文字：16sp 常规
   - 分组标题：14sp 常规
   - 导航文字：12sp 常规

5. **交互**：
   - 开关：深绿色轨道（开启）/ 浅灰色轨道（关闭）
   - 时间选项：点击可选择时间
   - 返回箭头：点击返回上一页
