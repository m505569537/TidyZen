# 我的勋章墙设计稿详细描述

## 页面整体布局
页面采用垂直流式布局，分为**顶部导航栏**、**用户信息卡片**、**成就分类标签栏**、**勋章网格区**、**升级进度区**、**底部Tab导航栏**六个核心区域，背景色为纯白色（#FFFFFF），整体风格日式极简，以治愈绿为主色调。大量留白，层次分明。

## 一、顶部导航栏（Top Navigation Bar）
- **位置与尺寸**：页面最顶部，高度约44px，背景白色（#FFFFFF），下方无明显分割线。
- **组件细节**：
  - 左侧：返回箭头图标（←），线条风格，深灰色（#333333），尺寸约24×24px，触摸区域不小于44×44px。
  - 中间：页面标题"我的勋章墙"，深灰色（#333333），字号18px，字重中等（Medium），居中对齐。
  - 右侧：无额外操作按钮，保持页面简洁。
- **内边距**：左右各16px，顶部距状态栏约8px。

## 二、用户信息卡片（User Info Card）
- **位置**：顶部导航栏下方，间距约16px。
- **卡片样式**：
  - 背景：深绿色渐变（主色 #2D6B5B → #3A8F7A），圆角16px。
  - 尺寸：宽度自适应（左右各留16px页面边距），高度约120px。
  - 内边距：上下16px，左右20px。
- **卡片内容**：
  - **左侧区域**：
    - 用户头像：圆形，直径约48px，浅绿色（#A8E6CF）背景，内部为深绿色（#2D6B5B）人物轮廓图标。
    - 用户昵称：白色（#FFFFFF），字号16px，字重中等（Medium）。
    - 等级标签：圆角矩形（圆角8px），白色半透明背景（rgba(255,255,255,0.2)），内有白色文字"Lv.5 整洁达人"，字号12px。
  - **右侧区域**：
    - 整洁得分：大字显示"85"，白色（#FFFFFF），字号36px，字重粗体（Bold）。
    - 得分标签：白色（#FFFFFF），字号12px，透明度80%，文字"整洁得分"。

## 三、成就分类标签栏（Category Tabs）
- **位置**：用户信息卡片下方，间距约16px。
- **标签样式**：3个标签横向排列，左右留白16px。
  - **选中态**"全部成就"：
    - 背景：深绿色（#2D6B5B），圆角20px。
    - 文字：白色（#FFFFFF），字号14px，字重中等（Medium）。
    - 内边距：水平16px，垂直8px。
  - **未选中态**"进阶之路""限时挑战"：
    - 背景：浅灰色（#F5F5F5），圆角20px。
    - 文字：中灰色（#666666），字号14px，字重常规（Regular）。
    - 内边距：水平16px，垂直8px。
- **标签间距**：标签之间间距8px。

## 四、勋章网格区（Medal Grid）
- **位置**：标签栏下方，间距约16px。
- **布局**：3列等宽网格，左右页面边距各16px，列间距12px，行间距20px。
- **勋章卡片（单个）**：
  - 尺寸：约100×120px（宽×高），水平居中于列。
  - 排列：上方圆形图标 + 下方文字标签，垂直居中。
  - **圆形图标**：直径约56px。
  - **文字标签**：位于图标下方，间距8px，字号12px，居中对齐，宽度不超过卡片宽度。

### 已解锁勋章（Unlocked）
- **圆形背景**：浅绿色（#A8E6CF）或淡黄色（#FFE082），圆角完全圆形。
- **图标颜色**：深绿色（#2D6B5B），线条风格，尺寸约28×28px，居中。
- **右下角徽章**：圆形小徽章，直径约18px，深绿色（#2D6B5B）背景，内有白色（#FFFFFF）对勾（✓）图标。
- **文字标签**：深灰色（#333333），字号12px，字重常规（Regular）。

### 未解锁勋章（Locked）
- **圆形背景**：浅灰色（#E0E0E0），圆角完全圆形。
- **图标颜色**：灰色（#9E9E9E），同款线条风格，尺寸约28×28px，居中。
- **右下角徽章**：圆形小徽章，直径约18px，灰色（#9E9E9E）背景，内有白色（#FFFFFF）锁形🔒图标。
- **文字标签**：浅灰色（#BDBDBD），字号12px，字重常规（Regular）。

### 勋章状态对比表

| 维度 | 已解锁（Unlocked） | 未解锁（Locked） |
|------|--------------------|--------------------|
| 圆形背景色 | #A8E6CF / #FFE082 | #E0E0E0 |
| 图标颜色 | #2D6B5B | #9E9E9E |
| 角标样式 | 对勾✓ | 锁🔒 |
| 角标背景色 | #2D6B5B | #9E9E9E |
| 文字颜色 | #333333 | #BDBDBD |

## 五、升级进度区（Upgrade Progress Section）
- **位置**：勋章网格下方，间距约24px。
- **卡片样式**：
  - 背景：白色（#FFFFFF），圆角12px，带浅灰色（#F5F5F5）阴影（阴影偏移：0 2px 8px rgba(0,0,0,0.06)）。
  - 内边距：上下16px，左右16px。
  - 左右页面边距：16px。
- **内容**：
  - 标题行：左侧文字"距下一等级"，深灰色（#333333），字号14px，字重中等。右侧数字"15/100"，深绿色（#2D6B5B），字号14px，字重粗体。
  - 进度条：高度约8px，圆角4px，背景浅灰色（#E0E0E0），填充部分深绿色（#2D6B5B），填充比例15%。
  - 进度条与标题行间距：12px。
  - 提示文字："再收集5枚勋章即可升级"，中灰色（#666666），字号12px，位于进度条下方，间距8px。

## 六、底部Tab导航栏（Bottom Tab Bar）
- **位置与尺寸**：页面最底部，高度约56px（含安全区），背景白色（#FFFFFF），顶部有1px浅灰色（#E0E0E0）分割线。
- **组件（4个Tab）**：从左到右依次为"首页""扫描""记录""设置"，每个Tab含图标+文字。
  - **首页（未选中）**：
    - 图标：深灰色（#666666）房子图标，尺寸24×24px。
    - 文字："首页"，深灰色（#666666），字号10px。
  - **扫描（未选中）**：
    - 图标：深灰色（#666666）扫描框图标，尺寸24×24px。
    - 文字："扫描"，深灰色（#666666），字号10px。
  - **记录（选中态）**：
    - 图标：深绿色（#2D6B5B）时钟图标，尺寸24×24px，外有浅绿色（#E8F5E9）圆角矩形背景（圆角12px，内边距4px 12px）。
    - 文字："记录"，深绿色（#2D6B5B），字号10px。
  - **设置（未选中）**：
    - 图标：深灰色（#666666）齿轮图标，尺寸24×24px。
    - 文字："设置"，深灰色（#666666），字号10px。
- **对齐**：4个Tab平均分布，图标与文字垂直居中对齐，间距4px。

## 设计规范总结

| 维度 | 规范内容 |
|------|----------|
| 设计风格 | 日式极简 + 治愈绿主题，留白充足，层次清晰 |
| 主色调 | #2D6B5B（治愈深绿），辅以 #A8E6CF、#E8F5E9 浅绿梯度 |
| 字体层级 | 3级：标题18px Medium、正文14px Regular、辅助12px Regular |
| 圆角规范 | 大卡片16px、标签/角标20px、进度条/小元素4px |
| 勋章状态 | 已解锁=彩色背景+深绿图标+对勾；未解锁=灰色背景+灰色图标+锁 |
| 整体色调 | 白色基底 + 绿色强调 + 灰色辅助，温暖治愈 |
