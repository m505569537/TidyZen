# 房间模板管理页面设计稿描述

## 页面整体布局
- 布局：垂直线性布局，顶部状态栏、主内容区、底部导航栏
- 设计风格：现代极简风，注重留白与呼吸感
- 主色调：深绿色（主题色）、米色（辅助背景色）、浅灰色（背景及标签色）、白色（卡片背景）

## 顶部状态栏
- 高度：约 44px（iOS 标准）
- 左侧：图标（图表样式） + 文本"整洁得分: 85"
- 右侧：用户头像图标（圆形轮廓）
- 背景：白色或极浅的灰色（#F9F9F9）

## 主内容区
- 背景：浅灰色（#F5F5F5）
- 顶部内边距：约 20px

### 空间类型定制标题区
- 主标题："空间类型定制"
  - 字号：22px，加粗（Font Weight: 600）
  - 颜色：纯黑或深灰色（#1A1A1A）
  - 对齐：左对齐
  - 下方间距：8px
- 副标题/说明文字："选择您当前的居住场景，AI 将为您生成最符合空间的动线优化建议与整理方案。"
  - 字号：14px，常规字重
  - 颜色：中灰色（#666666）
  - 行高：1.5倍
  - 下方间距：24px

### 空间选择卡片列表
- 容器：垂直排列的卡片列表
- 卡片间距：16px
- 卡片样式：
  - 背景：白色（#FFFFFF）
  - 圆角：12px
  - 内边距：上下左右均 16px
  - 外边距：水平方向有 16px 的页面边距
  - 投影：无，依赖卡片间的灰色背景制造层次感

#### 卡片内部元素（以"出租屋"卡片为例）
1. **图标**：
   - 容器：正方形，圆角 8px，背景为浅绿色（#E8F5E9）
   - 内容：深绿色（#2E7D32）的线条图标，尺寸约 24x24px
   - 位置：位于卡片左上角
2. **标题**：
   - 文本："出租屋"
   - 字号：16px，加粗
   - 颜色：黑色（#1A1A1A）
   - 位置：图标下方，左对齐，与图标底部间距 12px
3. **描述**：
   - 文本："聚焦收纳空间不足与多功能分区优化，平衡生活与工作节奏。"
   - 字号：13px，常规字重
   - 颜色：灰色（#666666）
   - 行高：1.5倍
   - 位置：标题下方，间距 8px
4. **标签组**：
   - 布局：水平排列的 Flex 容器，有 8px 间距
   - 标签样式：
     - 背景：浅灰色（#F0F0F0）
     - 文本颜色：深灰色（#444444）
     - 字号：11px
     - 圆角：10px（全圆角）
     - 内边距：水平 10px，垂直 4px
   - 位置：描述文本下方，卡片底部内边距处，间距 12px

#### 卡片状态差异化（"卧室"卡片 - 选中状态）
- 边框：1.5px 实线，颜色为主题深绿色（#2E7D32）
- 右上角选中图标：圆形，深绿色填充，内有白色对勾。尺寸约 20x20px
- 背景：仍为白色
- 图标背景色：米黄色（#FFF8E1），与其他卡片的浅绿色区分

## 主要操作按钮
- 文本："确认并开始优化"
- 样式：
  - 背景：深绿色（#2E7D32）
  - 文本颜色：白色
  - 字号：16px，中等字重
  - 圆角：28px（胶囊形状）
  - 高度：约 48px
  - 宽度：水平居中，左右留有 40px 的边距
  - 位置：卡片列表下方，间距 24px

     - 字号：13px

  3. **装饰图标**：右侧有一个大型的人头轮廓图标，颜色为极浅的绿色（#E0F2F1），尺寸约 60x60px

## 精确复刻关键点
1. **颜色体系**：严格使用深绿（#2E7D32）、米黄（#FDF6EC / #E8F5E9）、浅灰（#F5F5F5 / #F0F0F0）、白（#FFFFFF）、深灰/黑文字色
2. **圆角**：整体大圆角（12px），按钮全圆角（28px），标签全圆角（10px）
3. **间距**：遵循 8px 倍数系统（8px，12px，16px，24px）
4. **字体**：使用无衬线字体，字号层级分明（标题16-22px，正文13-14px，标签11px）
5. **状态反馈**：选中状态需通过边框、图标、颜色三重反馈
6. **图标风格**：统一为简洁的线条风格
