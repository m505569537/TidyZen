# 修改密码页面设计规范

> TidyZen — 日式极简 + 治愈绿主题 · React Native Expo App

---

## 1. 整体页面布局

页面采用**单列纵向布局**，自上而下依次为：

```
┌─────────────────────────────────┐
│  顶部导航栏                       │
├─────────────────────────────────┤
│                                 │
│      🛡️ 安全图标（圆形背景）        │
│      描述性辅助文字               │
│                                 │
│  ┌───────────────────────────┐  │
│  │  表单卡片（白色圆角容器）    │  │
│  │                           │  │
│  │  旧密码                    │  │
│  │  ─────────────────────    │  │
│  │  新密码                    │  │
│  │  ─────────────────────    │  │
│  │  确认新密码                 │  │
│  │                           │  │
│  │  [    提交修改 按钮    ]    │  │
│  └───────────────────────────┘  │
│                                 │
│  ┌───────────────────────────┐  │
│  │  💡 密码要求提示区域         │  │
│  └───────────────────────────┘  │
│                                 │
└─────────────────────────────────┘
```

- 页面背景色：`#F5F5F5`（浅灰）
- 各区域之间留有充足呼吸间距，避免视觉拥挤

---

## 2. 顶部导航栏

| 属性 | 详情 |
|------|------|
| **背景色** | 透明（与页面背景 `#F5F5F5` 融合） |
| **高度** | 56px |
| **左右内边距** | 16px |
| **返回箭头** | 左侧，纯文字 chevron `<` 样式，无背景无边框，颜色 `#2E7D32` |
| **标题文字** | 「修改密码」，紧跟返回箭头右侧，左对齐，颜色 `#2E7D32`，字号 ~18px |
| **右侧元素** | 得分图标 + 「整洁得分: 85」，颜色 `#2E7D32`，字号 ~14px |

---

## 3. 英雄引导区域（图标 + 说明文字）

| 属性 | 详情 |
|------|------|
| **图标容器** | 圆形，直径 ~120px，背景色 `#E8F5E9`（浅治愈绿） |
| **图标** | 安全盾牌/锁刷新图标，颜色 `#2E7D32` |
| **说明文字** | 居中显示，颜色 `#666666`（中灰），字号 ~14px，行高 20px |
| **导航栏到图标间距** | ~32px |
| **图标到说明文字间距** | ~16px |

---

## 4. 表单卡片

### 4.1 卡片容器

| 属性 | 详情 |
|------|------|
| **背景色** | `#FFFFFF`（白色） |
| **圆角** | 16px |
| **左右外边距** | 16px |
| **内边距** | 上下 24px，左右 20px |
| **与上方间距** | 32px（说明文字底部到卡片顶部） |

### 4.2 表单字段

三个字段纵向堆叠，样式一致：

#### 旧密码

| 属性 | 详情 |
|------|------|
| **标签** | 「旧密码」，颜色 `#2E7D32`，字号 ~14px，中等字重 |
| **占位文字** | 「请输入当前密码」，颜色 `#9E9E9E` |
| **输入框高度** | 48px |
| **输入框边框** | 无可见边框 |
| **右侧图标** | 👁 密码可见性切换图标，颜色 `#666666` |
| **底部分隔线** | 颜色 `#E0E0E0`，细线 |

#### 新密码

| 属性 | 详情 |
|------|------|
| **标签** | 「新密码」，颜色 `#2E7D32`，字号 ~14px |
| **占位文字** | 「至少8位字符」，颜色 `#9E9E9E` |
| **输入框高度** | 48px |
| **输入框边框** | 无可见边框 |
| **右侧图标** | 👁 密码可见性切换图标，颜色 `#666666` |
| **底部分隔线** | 颜色 `#E0E0E0`，细线 |

#### 确认新密码

| 属性 | 详情 |
|------|------|
| **标签** | 「确认新密码」，颜色 `#2E7D32`，字号 ~14px |
| **占位文字** | 「请再次输入新密码」，颜色 `#9E9E9E` |
| **输入框高度** | 48px |
| **输入框边框** | 无可见边框 |
| **右侧图标** | 无（确认字段无需切换可见性） |
| **底部分隔线** | 无（最后一个字段） |

### 4.3 字段间距

| 间距 | 值 |
|------|------|
| 标签到输入框 | 12px |
| 输入框到底部分隔线 | 8px |
| 分隔线到下一个标签 | 8px |
| 最后一个输入框到提交按钮 | 24px |

---

## 5. 提交按钮

| 属性 | 详情 |
|------|------|
| **背景色** | `#2E7D32`（深治愈绿） |
| **文字颜色** | `#FFFFFF`（白色） |
| **文字** | 「提交修改」，字号 ~16px，中等字重 |
| **左侧图标** | 白色盾牌/勾选图标 |
| **圆角** | 28px（胶囊/药丸形） |
| **高度** | 56px |
| **宽度** | 卡片内全宽（减去左右 20px 内边距） |
| **卡片底部内边距** | 按钮底部距卡片底边 ~24px |

---

## 6. 密码要求提示区域

| 属性 | 详情 |
|------|------|
| **背景色** | `#E8F5E9`（浅治愈绿） |
| **圆角** | 与卡片一致风格 |
| **左侧图标** | ℹ️ 信息图标，颜色 `#2E7D32` |
| **提示文字** | 颜色 `#666666`，字号 ~13px，行高 22px |
| **内边距** | 上下 16px，左右 16px |
| **与卡片间距** | 16px |

---

## 7. 完整色板

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#F5F5F5` | 浅灰，中性底色 |
| 主题绿（导航/标签/按钮/图标） | `#2E7D32` | 深治愈绿，主强调色 |
| 浅绿背景（图标容器/提示区） | `#E8F5E9` | 柔和治愈绿，辅助背景 |
| 卡片背景 | `#FFFFFF` | 纯白 |
| 主要辅助文字 | `#666666` | 中灰 |
| 占位文字 | `#9E9E9E` | 浅灰 |
| 分隔线 | `#E0E0E0` | 极浅灰 |
| 图标辅助色（眼睛等） | `#666666` | 中灰 |
| 按钮/导航文字 | `#FFFFFF` | 纯白 |
