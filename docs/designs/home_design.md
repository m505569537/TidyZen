# 首页设计稿详细描述

## 页面整体布局
页面采用垂直流式布局，分为**顶部导航栏**、**主体内容区**、**底部Tab导航栏**三个核心区域，背景色为纯白色（#FFFFFF），整体风格简洁清新，以绿色为主色调。

## 一、顶部导航栏（Top Navigation Bar）
- **位置与尺寸**：页面最顶部，高度约44px，背景白色，下方无明显分割线。
- **组件细节**：
  - 左侧：深灰色（#666666）列表图标，尺寸约24x24px，线条风格。
  - 中间：黑色（#000000）文字"整洁得分：85"，字号16px，字重常规（Regular），居中对齐。
  - 右侧：深灰色（#666666）用户头像图标，尺寸约24x24px，圆形轮廓+内部人物线条。

## 二、主体内容区（Main Content Area）
从上到下依次为**整洁得分展示区**、**杂乱提示区**、**核心功能区**、**最近对比区**，各区域间距约24px（垂直方向）。

### 1. 整洁得分展示区
- **核心组件**：环形进度条+中央数字。
- **细节**：
  - 环形进度条：主色为深绿色（#2D6B5B），进度占比85%（绿色环），剩余15%为浅灰色（#E0E0E0）背景环，外环无填充，内环白色（#FFFFFF）。环形外径约200px，内径约140px，厚度约30px。
  - 中央数字："85"，深绿色（#2D6B5B）粗体（Bold），字号48px，居中对齐。
  - 数字下方："当前得分"，黑色（#000000）常规字体，字号14px，居中对齐。
- **背景**：白色（#FFFFFF），与页面背景一致。

### 2. 杂乱提示区
- **组件**：圆角矩形提示框，居中显示。
- **细节**：
  - 背景：浅红色（#FFF0F0），圆角12px，高度约36px，宽度自适应（内容撑开）。
  - 左侧图标：红色（#E53935）三角形警告图标，尺寸约16x16px。
  - 文字："检测到3处杂乱"，黑色（#000000）常规字体，字号14px，与图标间距8px。
- **位置**：环形进度条下方，垂直居中对齐。

### 3. 核心功能区
- **标题栏**：
  - 左侧："核心功能区"，黑色（#000000）粗体（Bold），字号20px。
  - 右侧："查看全部"，深绿色（#2D6B5B）常规字体，字号14px。
  - 间距：标题与下方卡片垂直间距16px。
- **功能卡片**：
  - 背景：白色（#FFFFFF），圆角8px，带浅灰色（#F5F5F5）阴影（阴影偏移：0 2px 8px）。
  - 卡片顶部：灰色到白色的水平渐变（左#E0E0E0，右#FFFFFF），高度约80px。
  - 渐变区域内标签：
    - 左侧绿色标签（#2D6B5B）：圆角12px，白色（#FFFFFF）文字"3分钟完成"，字号12px，内边距4px 8px。
    - 右侧橙色标签（#FF9800）：圆角12px，白色（#FFFFFF）文字"必做"，字号12px，内边距4px 8px，与绿色标签间距8px。
  - 标签下方（卡片内容区）：
    - 标题："椅子急救法"，黑色（#000000）粗体，字号18px，内边距16px（左右）。
    - 说明文字："将椅子上的衣物分类，常穿的挂起，待洗的放入脏衣篓。"黑色（#000000）常规字体，字号14px，行高1.5，内边距16px（左右）。
    - 操作按钮：深绿色（#2D6B5B）圆角按钮，高度44px，圆角20px，内边距0 16px，底部间距16px。按钮左侧有白色（#FFFFFF）播放图标（尺寸16x16px），右侧文字"开始整理"（白色粗体，字号16px）。

### 4. 最近对比区
- **标题**："最近对比"，黑色（#000000）粗体，字号20px，内边距0（左右）。
- **对比卡片**：
  - 背景：白色（#FFFFFF），圆角8px，带浅灰色阴影，高度约120px，内边距16px。
  - 内容布局：左右分栏，左侧占70%，右侧占30%。
  - 左侧两个方形区域：
    - 前置状态（Before）：灰色（#F5F5F5）背景，圆角4px，左上角有深灰色（#666666）矩形标签，内有白色文字"Before"（字号10px）。
    - 后置状态（After）：灰色（#F5F5F5）背景，圆角4px，左上角有深绿色（#2D6B5B）矩形标签，内有白色文字"After"（字号10px）。
    - 两个方形间距8px，垂直居中。
  - 右侧对比结果：
    - 向上箭头：深绿色（#2D6B5B），尺寸约24x24px，线条风格。
    - 文字："+15分"，深绿色（#2D6B5B）粗体，字号14px，与箭头垂直对齐（间距4px）。

## 三、底部Tab导航栏（Bottom Tab Bar）
- **位置与尺寸**：页面最底部，高度49px，背景白色，顶部有1px浅灰色（#E0E0E0）分割线。
- **组件（4个Tab）**：从左到右依次为"首页""扫描""记录""设置"，每个Tab含图标+文字。
  - **首页（选中状态）**：
    - 图标：深绿色（#2D6B5B）房子图标，尺寸24x24px，外有浅绿色（#E8F5E9）圆角矩形背景（圆角12px）。
    - 文字："首页"，深绿色（#2D6B5B）常规字体，字号10px。
  - **扫描（未选中）**：
    - 图标：深灰色（#666666）扫描框图标，尺寸24x24px。
    - 文字："扫描"，深灰色（#666666）常规字体，字号10px。
  - **记录（未选中）**：
    - 图标：深灰色（#666666）时钟+箭头图标，尺寸24x24px。
    - 文字："记录"，深灰色（#666666）常规字体，字号10px。
  - **设置（未选中）**：
    - 图标：深灰色（#666666）齿轮图标，尺寸24x24px。
    - 文字："设置"，深灰色（#666666）常规字体，字号10px。
- **对齐**：4个Tab平均分布，图标与文字垂直居中对齐，间距4px。

## 设计规范总结
| 维度       | 规范内容                                                                 |
|------------|--------------------------------------------------------------------------|
| **主色调** | 深绿色（#2D6B5B），用于核心交互、选中状态、标题等。                       |
| **辅助色** | 橙色（#FF9800，必做标签）、浅红色（#FFF0F0，杂乱提示背景）、浅绿色（#E8F5E9，选中背景）。 |
| **文字色** | 标题/重要文字：黑色（#000000）；辅助文字：深灰色（#666666）。             |
| **背景色** | 页面/卡片：白色（#FFFFFF）；灰色区域：#E0E0E0/#F5F5F5。                  |
| **圆角**   | 卡片/按钮：8-20px；标签：12px；Tab选中背景：12px。                        |
| **阴影**   | 卡片/对比区：0 2px 8px #F5F5F5（浅灰色）。                                |
| **字体**   | 标题：粗体（Bold）；正文：常规（Regular）；字号10-48px（层级清晰）。       |
