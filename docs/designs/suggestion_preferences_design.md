# 建议库偏好页面设计稿描述

## 页面整体结构
- 从上到下：顶部导航栏 → 头部Banner区 → 说明文字区 → 杂物类型过滤区 → 底部提示卡 → 底部导航栏
- 整体背景：浅灰色（#F5F5F5）
- 卡片/列表项背景：白色（#FFFFFF）

## 顶部导航栏（Toolbar）
- 布局：水平排列，左（返回箭头）→ 中（标题）→ 右（搜索+用户图标）
- 高度：56dp
- UI元素：
  - 左侧：返回箭头（<），颜色 #333333，大小 24sp
  - 中间：标题"设置中心"，字体 18sp，颜色 #333333，居中对齐
  - 右侧：搜索图标（放大镜）+ 用户图标（头像轮廓），颜色 #333333，大小 24sp，两者间距 8dp

## 头部Banner区
- 布局：宽度 100% - 左右padding（16dp），高度约 200dp
- UI元素：
  - 背景图：室内场景（窗帘、绿植、木板），半透明遮罩+白色文字
  - 文字：
    - 主标题："建议库偏好"，字体 24sp，颜色 #FFFFFF，加粗，垂直居中
    - 副标题："定制你的 AI 整理管家"，字体 16sp，颜色 #FFFFFF，常规字重，与主标题间距 8dp

## 说明文字区
- 布局：白色卡片（圆角 8dp），外边距 上下16dp + 左右16dp，内边距 16dp
- UI元素：
  - 文字内容："选择你希望 AI 在房间分析中重点识别的杂物类型。关闭开关后，该类别的整理建议将不再出现在分析报告中，让建议结果更符合你的生活习惯。"
  - 样式：字体 14sp，颜色 #333333，行高 1.6，左对齐

## 杂物类型过滤区

### 标题
- 文字："杂物类型过滤"，字体 16sp，颜色 #333333，外边距 上下8dp + 左右16dp，左对齐

### 列表项（共5个，样式一致）
- 布局：白色卡片（圆角 8dp），外边距 上下8dp + 左右16dp，内边距 16dp，水平排列（左图标→中文字→右开关）
- UI元素：
  1. **左侧圆形图标**：
     - 直径 48dp，背景色（按类别）：
       - 衣物与织物/纸箱与包裹：#E8F5E9（浅绿）
       - 桌面杂物/地面堆积：#F5F5F5（浅灰）
       - 电线管理：#FFF3E0（浅黄）
     - 图标：深灰色（#333333），大小 24dp，居中于圆形容器

  2. **中间文字区**：
     - 标题：类别名称（如"衣物与织物"），字体 16sp，颜色 #333333，加粗
     - 描述：类别说明（如"床面、沙发或椅子上的散乱衣物"），字体 14sp，颜色 #666666，行高 1.4，与标题间距 4dp

  3. **右侧Toggle开关**：
     - 尺寸：宽 48dp，高 24dp，圆角 12dp
     - 样式：打开状态背景 #2196F3（蓝色），关闭状态背景 #999999（灰色）；开关内对勾为白色
     - 间距：与中间文字区的间距 16dp

## 底部提示卡
- 布局：白色卡片（圆角 8dp），外边距 上下16dp + 左右16dp，内边距 16dp，虚线边框（颜色 #CCCCCC，线宽 1dp，线型 dashed）
- UI元素：
  - 顶部图标：绿色小图标（如四个点/星星），颜色 #4CAF50，大小 24dp，居中
  - 文字：
    - 主文字："AI 正在学习你的整理风格"，字体 16sp，颜色 #333333，加粗
    - 副文字："根据你的开关记录，我们会自动微调 AI 的评分权重，为你提供更精准的整洁度评分。" 字体 14sp，颜色 #666666，行高 1.4

## 颜色与间距速查
| 元素 | 颜色/间距 | 说明 |
|------|-----------|------|
| 页面背景 | #F5F5F5 | 浅灰色，覆盖整体 |
| 卡片/列表项背景 | #FFFFFF | 白色，突出内容 |
| 标题文字 | #333333 | 深灰色，用于导航/列表标题 |
| 描述文字 | #666666 | 浅灰色，用于补充说明 |
| Banner文字 | #FFFFFF | 白色，与背景图形成对比 |
| Toggle打开 | #2196F3 | 蓝色，视觉引导 |
| 选中导航项 | 背景#E8F5E9 + 图标#4CAF50 | 浅绿+深绿，突出当前页 |
| 外边距（卡片/列表项） | 上下8dp/16dp + 左右16dp | 保证呼吸感与对齐 |
| 内边距（卡片/列表项） | 16dp | 内容与边界的间距 |
