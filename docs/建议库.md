# 《智能房间整洁助手》标准化建议库（V2.0）

> **文档定位**：App 后台策略配置文档，直接对接前端 UI 与 AI 识别结果。
> **设计原则**：5分钟完成、零成本、纯视觉改善。
> **V2.0 变更**：每场景扩充至 3-5 条建议；新增元数据字段；场景10独立为氛围类；修复验收标准；增加误识别说明和冷启动策略。

---

## 一、基础配置

| 配置项 | 内容 |
| :--- | :--- |
| **适用版本** | MVP (V1.0) |
| **建议总数** | 10 个场景 × 3~5 条 = 35 条建议 |
| **匹配逻辑** | 识别到多种杂物时，按 `识别特征标签体系.md` 中的优先级排序推荐 |
| **展示规则** | 一次展示 1 条主建议 + 1 条备选，避免信息过载 |
| **反馈兜底** | 识别不准时，用户可手动选择 10 个场景按钮 |

---

## 二、建议元数据字段说明

每条建议包含以下字段：

| 字段 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **id** | string | 建议唯一标识 | `S01-A01` |
| **difficulty** | enum | 难度等级 | `easy`（⭐）/ `medium`（⭐⭐） |
| **time_cost** | string | 预计耗时 | "3分钟" |
| **items_needed** | string[] | 所需物品（用户可能没有的） | `["长尾夹×2"]` 或 `[]`（零成本） |
| **room_type** | string[] | 适用房型 | `["small", "medium"]` / `["all"]` |
| **expected_effect** | string | 预期改善程度 | "视觉整洁度+30%" |
| **type** | enum | 建议类型 | `must_do`（必做）/ `optional`（备选） |

**难度等级定义**：
- `easy`（⭐）：不需要任何工具，徒手完成，3分钟以内
- `medium`（⭐⭐）：需要简单工具（挂钩、纸箱等），5分钟以内

**房型定义**：
- `small`：10㎡以下（出租屋、宿舍）
- `medium`：10-20㎡（普通卧室）
- `all`：不限房型

## 五、常见误识别场景

AI 在冷启动阶段可能产生的误识别，需在 Prompt 中明确告知模型避免：

| 误识别场景 | 原因 | 避免策略 |
|------------|------|----------|
| 装饰画/海报误认为杂物 | 墙上悬挂的方形物体与纸箱相似 | Prompt 中明确"墙面上的装饰物不计入杂物" |
| 正常叠放的衣物误认为散落 | 整齐叠放和散落在视觉上可能相似 | 增加"整齐度"判断：有明显叠放规律的不算散落 |
| 宠物用品误认为杂物 | 猫窝、狗垫形状与杂物类似 | 增加宠物用品标签，识别后排除 |
| 盆栽/绿植误认为杂物 | 颜色和形状可能干扰 | 增加植物标签，绿植不算杂物 |
| 正常使用的物品误认为杂乱 | 电脑、水杯等"正在使用"的物品 | 桌面上的"高频使用物品"（电脑、手机、水杯）不计入杂物 |
| 深色地板/地毯误认为脏乱 | 大面积深色区域可能被误判为污渍 | 结合光线标签判断，光线正常时不将深色区域判定为脏乱 |

## 六、冷启动与兜底策略

### 6.1 多场景同时匹配时的推荐逻辑

```python
# 参见 识别特征标签体系.md 第三章 优先级排序规则
# 一次最多展示 2 条建议（1主+1备选）+ 1条氛围附加建议
```

### 6.2 置信度不足时的兜底

| 情况 | 处理方式 |
|------|----------|
| 所有识别结果置信度 ≥ 0.8 | 直接展示匹配场景的建议 |
| 最高置信度在 0.6-0.8 | 展示建议 + 附"可能不太准，点这里纠错" |
| 所有识别结果置信度 < 0.6 | 不展示具体识别，只展示兜底建议 |
| 无任何杂物识别（干净房间） | 展示"房间很整洁！试试打开窗帘让光线更好？"（S10） |

### 6.3 兜底建议（万能解法）

当无法确定具体场景时，按检测到的**主要区域**推荐：

| 检测到的主要区域 | 兜底建议 |
|-----------------|----------|
| 地面有杂物 | → S04 踢角法 |
| 床面不整洁 | → S05 豆腐块平铺法 |
| 桌面凌乱 | → S03 托盘归集法 |
| 无法判断 | → S03 托盘归集法（万能解法） |

## 七、运营与迭代说明

1. **文案规范**：UI 文案需口语化（如"踢走"、"塞进去"），禁用书面语（如"请您收纳"）
2. **建议轮换**：同一场景多次识别时，轮换展示不同建议，避免重复体验（V1.1 实现）
3. **数据驱动迭代**：收集纠错数据和建议执行率，定期优化建议文案和 Prompt
4. **短视频脚本**：每条建议配套 15 秒内短视频，存储本地支持离线播放
