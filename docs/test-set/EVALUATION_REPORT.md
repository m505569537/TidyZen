## 二、S4 prompt 改动内容（services/ai.ts BUILD_ANALYSIS_PROMPT）

1. **床铺被子规则修正**（关键 bug）：
   - 原：`床铺 — 散乱的衣物、杂物（被子枕头不算）`
   - 新：`床铺 — 散乱的衣物、杂物；明显凌乱（揉成团、堆积未铺、歪斜散落）的被子/枕头计为 pillow_blanket，整齐叠放/正常铺好的不算`
   - 效果：S05 两张床铺图 pillow_blanket 漏检 → 检出，评分从 94/81 → 50/71（回归合理区间）

2. **家具排除补充说明**：
   - 原：`不要把家具(床、桌、椅、柜)、书架、墙上的画/海报、装饰品当成杂物`
   - 新：追加 `正常铺好的被子/枕头是家具/用品不算杂物，但明显凌乱揉成一团的被褥算杂物（pillow_blanket）`

3. **新增场景判定优先级（第 11 条）**：
   - `如果画面是房间整体视角、能看到床/沙发/书桌/浴室柜等主要家具，scene 优先填 bedroom | living_room | bathroom | desk_area；只有画面完全是地面特写（无任何家具出现，或家具只占极小边角）才填 floor。杂物堆在墙角/地面不改变房间类型判断`
   - 效果：S02-001（玄关纸箱）floor → living_room ✓；S02-002（阳台纸箱）仍判 floor（见下）

## 三、剩余 2 个场景"失败"分析（均为 GT 标注边界，非模型错误）

### S02-002-living_room-bright（期望 living_room，判 floor）
- 画面：阳台窗边堆纸箱，**无明显家具** → 模型按新规则第 11 条"无家具→floor"执行，**行为符合规则**
- 判定：可接受。此类"纯地面杂物"图判 floor 对用户无实质影响（建议内容仍正确）
- 可选优化：prompt 再补一句"即使无家具，若有明显窗户/阳台/玄关等房间空间感，优先 living_room"（收益低，暂缓）

### S04-001-floor-normal（期望 floor，判 bedroom）
- 画面：卧室双床间地面俯视特写，**图中可见床** → 模型按第 11 条"能看到床→bedroom"执行，**行为符合规则**
- 判定：**合理正确**。GT 期望 floor 标注过严——图里有床就应判 bedroom。建议修正 GT
