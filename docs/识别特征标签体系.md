# 《智能房间整洁助手》识别特征标签体系（V1.0）

> **文档定位**：建议库的配套文档，定义每个场景的 AI 识别规则，直接对接 mimo-v2.5-pro 的视觉理解输出。
> **标签体系参考**：基于 COCO 80 类物体筛选 + 自定义房间杂物标签。

---

## 一、标签定义

### 1.1 物体标签（label）

| 标签 ID | 中文名 | 对应 COCO 类 | 说明 |
|---------|--------|-------------|------|
| `clothing` | 衣物 | shirt, pants, jacket, dress 等 | 散落的衣物，含帽子、围巾 |
| `cardboard_box` | 纸箱/快递盒 | —（自定义） | 瓦楞纸箱、快递包装盒 |
| `cable` | 电线/数据线 | —（自定义） | 充电线、插线板、黑色线状物 |
| `book` | 书籍/纸张 | book | 平躺或堆叠的书本、文件 |
| `bottle` | 瓶罐 | bottle, cup | 洗护瓶、水杯、罐子 |
| `food_container` | 外卖/食物容器 | —（自定义） | 外卖盒、塑料袋、零食包装 |
| `shoe` | 鞋子 | shoe | 散落的鞋 |
| `pillow_blanket` | 被褥/枕头 | —（自定义） | 未叠的被子、掉落的枕头 |
| `trash` | 垃圾 | —（自定义） | 明显的废弃物、垃圾袋 |
| `other_clutter` | 其他杂物 | —（自定义） | 无法归类的杂乱物品 |

### 1.2 位置标签（scene）

| 标签 ID | 中文名 | 说明 |
|---------|--------|------|
| `bedroom` | 卧室 | 含床、衣柜、床头柜 |
| `living_room` | 客厅 | 含沙发、茶几、电视柜 |
| `bathroom` | 卫生间 | 含洗漱台、马桶、淋浴区 |
| `desk_area` | 桌面区域 | 书桌、餐桌、梳妆台 |
| `floor` | 地面 | 任何房间的地面区域 |

### 1.3 光线标签（lighting）

| 标签 ID | 中文名 | 判断标准 |
|---------|--------|----------|
| `bright` | 明亮 | 自然光充足或灯光全开 |
| `normal` | 正常 | 基本照明，无明显暗角 |
| `dim` | 昏暗 | 阴暗、窗帘遮挡、灯光不足 |

## 二、场景识别规则

### 场景 01：衣物堆积（椅子/床上）

```yaml
scenario_id: "S01"
name: "衣物堆积"
detection_rules:
  - object: "clothing"
    location: ["bed", "chair", "sofa"]
    min_count: 3
    min_confidence: 0.7
    description: "床上/椅背/沙发上有超过3件散落衣物"
  - object: "pillow_blanket"
    location: ["bed", "chair"]
    state: "disordered"  # 褶皱、掉落状态
    min_confidence: 0.7
    description: "被褥褶皱严重或枕头掉落"
match_priority: 1  # 与其他场景冲突时的排序权重
```

### 场景 02：纸箱/快递盒（地面/桌面）

```yaml
scenario_id: "S02"
name: "纸箱/快递盒"
detection_rules:
  - object: "cardboard_box"
    location: ["floor", "desk_area"]
    min_area_ratio: 0.03  # 至少占画面3%（约A4纸大小）
    min_confidence: 0.8
    description: "画面中出现可识别的纸箱/快递盒"
match_priority: 2
```

### 场景 03：桌面杂物（书桌/餐桌）

```yaml
scenario_id: "S03"
name: "桌面杂物"
detection_rules:
  - location: ["desk_area"]
    object_types: ["bottle", "cable", "book", "food_container", "other_clutter"]
    min_total_count: 5  # 桌面物品总数>5
    min_confidence: 0.6
    description: "桌面上多种物品混杂，无明显规律摆放"
match_priority: 4  # 优先级低于地面和床面
fallback_rule: true  # 置信度<70%时的兜底场景
```

### 场景 04：地面杂物（动线阻碍）

```yaml
scenario_id: "S04"
name: "地面杂物"
detection_rules:
  - location: ["floor"]
    object_types: ["shoe", "cardboard_box", "clothing", "trash", "other_clutter"]
    min_total_count: 2
    min_confidence: 0.6
    description: "地面有非家具类散落物品"
match_priority: 1  # 最高优先级
```

### 场景 05：床上用品（视觉焦点）

```yaml
scenario_id: "S05"
name: "床上用品"
detection_rules:
  - object: "pillow_blanket"
    location: ["bed"]
    state: "disordered"
    min_confidence: 0.7
    description: "被子未叠、枕头歪斜、床单褶皱"
  - object: "clothing"
    location: ["bed"]
    min_count: 1
    min_confidence: 0.7
    description: "床上有衣物（与S01重叠时，优先S01）"
match_priority: 2
conflict_with: ["S01"]  # 与S01冲突时，衣物>3件走S01，否则走S05
```

### 场景 06：电线缠绕（视觉焦虑）

```yaml
scenario_id: "S06"
name: "电线缠绕"
detection_rules:
  - object: "cable"
    location: ["desk_area", "floor"]
    min_count: 3  # 至少3条线交叉
    min_confidence: 0.6
    description: "桌面或地面有多条黑色线状物交叉缠绕"
match_priority: 5
```

### 场景 07：洗漱台/瓶罐（卫生间）

```yaml
scenario_id: "S07"
name: "洗漱台瓶罐"
detection_rules:
  - object: "bottle"
    location: ["bathroom"]
    min_count: 3
    min_confidence: 0.7
    description: "洗漱台有多个瓶罐，倒伏或摆放凌乱"
  - location: ["bathroom"]
    object_types: ["bottle", "other_clutter"]
    disorder_score: 0.6  # AI 判断摆放整齐度
    min_confidence: 0.6
    description: "卫生间台面整体凌乱"
match_priority: 6
```

### 场景 08：食物残渣/外卖袋（卫生）

```yaml
scenario_id: "S08"
name: "食物残渣/外卖"
detection_rules:
  - object: "food_container"
    location: ["desk_area", "floor", "bed"]
    min_count: 1
    min_confidence: 0.7
    description: "画面中有外卖盒、塑料袋、零食包装"
match_priority: 3  # 卫生问题优先级较高
```

### 场景 09：书籍/纸张（视觉压迫）

```yaml
scenario_id: "S09"
name: "书籍/纸张"
detection_rules:
  - object: "book"
    location: ["desk_area", "floor", "bed"]
    min_count: 3
    state: "flat_or_tilted"  # 平躺或倾斜堆叠
    min_confidence: 0.7
    description: "书本平躺或倾斜堆叠，未竖立摆放"
match_priority: 6
```

### 场景 10：光线/氛围（建议类，非杂物）

```yaml
scenario_id: "S10"
name: "光线/氛围"
detection_rules:
  - lighting: "dim"
    min_confidence: 0.7
    description: "室内光线不足，窗帘遮挡或灯光昏暗"
match_priority: 10  # 最低优先级，仅作为加分建议
category: "ambiance"  # 独立类别，不属于"杂物清理"
```

## 三、优先级排序规则

当 AI 同时识别到多个场景时，按以下规则排序：

```python
# 伪代码：场景匹配优先级
PRIORITY_ORDER = [
    "S04",  # 地面杂物（动线安全，最高优先）
    "S08",  # 食物残渣（卫生问题，高优先）
    "S01",  # 衣物堆积
    "S02",  # 纸箱/快递盒
    "S05",  # 床上用品
    "S03",  # 桌面杂物
    "S06",  # 电线缠绕
    "S07",  # 洗漱台瓶罐
    "S09",  # 书籍/纸张
    "S10",  # 光线/氛围（仅作附加建议）
]

def recommend_scenes(detection_results):
    matched = [s for s in PRIORITY_ORDER if s in detection_results]
    primary = matched[0]      # 主建议：优先级最高的场景
    secondary = matched[1]    # 备选建议：第二优先场景
    bonus = "S10" if "S10" in matched and "S10" not in [primary, secondary] else None
    return primary, secondary, bonus
```

- **一次最多展示 2 条建议**（1 主 + 1 备选），避免信息过载
- 光线/氛围（S10）仅作为附加建议，不占主/备选名额
- 无任何场景匹配时，fallback 到 S03（托盘归集法，万能解法）

## 四、置信度与纠错机制

### 4.1 置信度阈值

| 置信度区间 | 处理方式 |
|------------|----------|
| ≥ 0.8 | 直接展示建议，标记"AI 高置信识别" |
| 0.6 - 0.8 | 展示建议，附"可能不太准，点这里纠错" |
| < 0.6 | 不展示该识别结果，fallback 到兜底场景 |

### 4.2 用户纠错流程

```
用户点击"不准" → 展示10个场景按钮供手动选择 → 用户选择正确场景 → 记录纠错数据
                                                                            ↓
                                                              后续用于 Prompt 优化和模型微调
```
